# archer.bluetooth

Omarchy Bluetooth panel with a hover tooltip showing connected devices.

A modified copy of the built-in `omarchy.bluetooth` plugin from [Omarchy](https://github.com/basecamp/omarchy) (MIT). It replaces the stock plugin when enabled; `omarchy plugin remove archer.bluetooth` restores it.

Install: `omarchy plugin add <this repo's git URL> --enable`

Personal config, shared as-is: no support or compatibility promises.
